# Coding Assistants in Action

Here we highlight some recent applications of coding assistants to client cases

#  Financial Services Co

## Context
- **Project:** March-October 2024 backend code for generating marketing content
- **Use Cases:**
  - Increase unit test coverage: helpful for all but the most complex functions
  - General coding assistance
- **Tools Used:** GitHub Copilot in IDE (e.g., PyCharm)
- **Legal:** GitHub Copilot license came from Financial Services Co.
- **Assisting the Assistant:** Need to give Copilot some help on the first unit test for a function

## By the Numbers
- **Code coverage achieved:** ~80%
- **Time saved:** ~50% (versus manual creation)
- **% of unit tests written by coding assistant:** ~80%

## Other Applications
- **Coding Style:** Used Black linter to follow PEP-8
- **PR Review:** Not used
